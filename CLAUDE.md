## Commands

```sh
cargo test                          # run all tests (unit + integration)
cargo nextest run                   # run tests with nextest (used in CI)
cargo test <test_name>              # run a specific test by name substring
cargo build                         # build (checks missing_docs lint)
cargo clippy --all-targets -- -D warnings
cargo fmt --all
just coverage                       # coverage report, gated at 80% lines
just run                            # plain HTTP server on 127.0.0.1:9000
just local                          # run via Lambda runtime emulator (cargo lambda watch)
just codegen                        # regenerate src/generated/ from lexicons/
just build                          # release build for Lambda arm64
```

## Architecture

Single-binary Axum app deployed as an AWS Lambda function (`provided.al2023`, arm64). `src/main.rs` picks
its runtime from `AWS_LAMBDA_FUNCTION_NAME`: the Lambda runtime when set, `axum::serve` on loopback
otherwise.

```
src/
  main.rs        entry points: Lambda runtime + local axum::serve
  lib.rs         AppState<A> + router wiring only
  config.rs      typed, validated, fail-fast
  error.rs       AppError + IntoResponse (the only place status codes are decided)
  domain.rs      ShortCode, TargetUrl, ShortLink — pure, no I/O
  store.rs       trait LinkStore + PdsLinkStore              (authed write side)
  resolver/      trait LinkResolver + slingshot/direct/chained (public read side)
  session/       AuthStore enum + memory/file impls          (OAuth token persistence)
  api/           thin HTTP handlers + extractors
```

Dependency rule: `api` → `domain`/`store`/`resolver`; `domain` depends on nothing. `jacquard` is confined to
`store.rs`, `session/`, `resolver/direct.rs` and `auth.rs` — do not let it leak back into handlers.

**Request flow:**
1. API Gateway HTTP API → Lambda → `router()` in `src/lib.rs`
2. `AppState<A>` (Arc-shared) holds the authenticator, the resolver chain, an `IdentityService`, a shared
   `reqwest::Client`, and `Config`. It is **generic over the authenticator**, which is the test seam:
   production wires `OAuthAuthenticator` (`Store = PdsLinkStore`), tests wire `FakeAuthenticator`
   (`Store = InMemoryLinkStore`). `router_with_state` monomorphises.
3. Auth-gated routes use the `AuthedUser<A>` extractor (`src/auth.rs`), which reads a session cookie
   holding `{did}|{session_id}`. The cookie is **not signed** — both halves are client-supplied, so it is
   only a lookup key, revalidated against the session store on every request. Named `__Host-session`
   outside local development; `session` on loopback, where the `__Host-` prefix's mandatory `Secure` would
   make it undeliverable.
4. Mutation and upstream-touching routes (`/api/login`, `/api/logout`, `/api/shorten`,
   `/api/shorten/{code}`, `/api/links`, `/oauth/callback`) go through `GovernorLayer`, keyed per client IP.

**Short URL lifecycle:**
- Create: `POST /api/shorten` → `putRecord` with `swapRecord: null`, so a duplicate code is a 409 from the
  PDS rather than a silent overwrite
- Resolve: `GET /@{handle}/{code}` → Slingshot first (2-hop: resolveHandle + getRecord), falling back to
  direct PDS resolution (3-hop: handle → DID → DID doc → PDS). Fallback is driven by typed
  `ResolveError` variants, never by string-matching error text
- Delete: `DELETE /api/shorten/{code}` → deletes the PDS record

**Key design notes:**
- `missing_docs` is enforced via `[lints.rust]` in `Cargo.toml` — all new public items need `///` docs
- Traits use AFIT with an explicit `-> impl Future<...> + Send`. No `#[async_trait]`, no `Box<dyn>`. The
  session store enum is the one documented exception (jacquard's `ClientAuthStore` is not object-safe)
- Make invalid states unrepresentable: `BaseUrl`, `NonZeroU64` rate limits, `ShortCode`, `TargetUrl`.
  Prefer deleting a bug's preconditions over catching it
- `AppError::BadRequest` takes `&'static str` on purpose — interpolating upstream text into a client-visible
  body is a compile error, not a review question
- `#[tracing::instrument]` requires `Debug` on args; use `skip_all` to avoid it on request types. If you
  declare `fields(x)`, record it — a declared-but-never-recorded field logs nothing
- Config loading: compiled defaults → `Config.toml` → `ATPR__` env vars (double-underscore separator).
  Invalid config aborts startup; it does not fall back
- Lexicon types in `src/generated/` are generated by `src/bin/codegen.rs` and **checked into git**. Run
  `just codegen` after editing `lexicons/` and commit the result; CI fails if they disagree. Do not edit
  `src/generated/` by hand
- Tests must be hermetic. `tests/` uses `wiremock`; `test_router()` points Slingshot at an unreachable
  address so nothing can silently start depending on the real one
- On Lambda, rate limiting is per-instance; the global limit is API Gateway throttling in `template.yaml`

**Known issue:** OAuth sessions live on the instance's `/tmp` and are per execution environment, so logins
fail intermittently under concurrency. The `session/` seam exists so a shared backend can be added without
touching handlers.
